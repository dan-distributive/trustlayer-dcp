TrustLayer · DCP

Speech deepfake scan on the DCP network

Score audio clips as genuine or synthetic with NAVER's pretrained AASIST model, converted to ONNX. Your browser only packs the files. Each DCP worker decodes, resamples, slices the audio into 4-second windows, adds the noise conditions you choose and runs the model.

Results

Margin = genuine logit − synthetic logit (a raw score, not a probability). The verdict uses the lowest-margin window, so one synthetic-looking window flags the file.

Per file

Each line is one condition; the points are 4-second windows across the clip. Below the dashed zero line, the model leans synthetic.

Model: AASIST (NAVER Corp., MIT) trained on ASVspoof 2019 LA. It was not trained on modern voice cloning or on partly edited audio, so treat verdicts as a demonstration, not a forensic result. Source: TrustLayer-Camp-QMIND-MVP.
